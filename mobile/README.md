# «Мой прогресс» — приложение для Android (Expo)

Внутри — та же страница `index.html`, что лежит в корне репозитория и открывается на GitHub Pages.
Приложение добавляет к ней:

- **напоминания с самого телефона** (вода, взвешивание, замеры, таблетки) — сервер на Render не нужен;
- хранение данных в памяти приложения (не пропадут при очистке браузера);
- экспорт резервной копии через «Поделиться» (в Telegram, на Диск, в почту);
- кнопку «Назад» (закрывает окно → возвращает на Главную → выходит).

## Файлы

| Файл | Что это |
|---|---|
| `App.js` | Экран приложения: показывает страницу, хранит данные, ставит напоминания |
| `reminders.js` | Расчёт, когда присылать напоминания |
| `app-html.js` | **Создаётся автоматически** из `../index.html` при `npm install` (или `npm run build-html`), в репозиторий не кладётся |
| `scripts/build-html.js` | Упаковывает `index.html` и картинки в `app-html.js` |
| `scripts/test-reminders.js` | Проверка напоминаний: `npm test` |
| `app.json`, `eas.json` | Настройки приложения и сборки |

## Поменяла что-то в index.html — как обновить приложение

1. Ничего упаковывать вручную не нужно: при сборке `index.html` подхватится сам. Для Expo Go на компьютере — `npm run build-html`.
2. Собрать новую версию (ниже). В `app.json` увеличить `android.versionCode` на 1.

## Посмотреть на телефоне через Expo Go

1. На компьютере в этой папке: `npm install`, затем `npx expo start`.
2. В Expo Go на телефоне отсканировать QR-код.

## Собрать APK (установочный файл)

1. `npm install`
2. `npx eas-cli@latest login` — войти в аккаунт expo.dev.
3. `npm run build:apk` — сборка идёт в облаке Expo ~10–15 минут.
4. По ссылке из консоли (или на expo.dev → Builds) скачать `.apk` на телефон и установить.

## Перенос данных из старого приложения (сайта)

1. В старом приложении: Главная → ⚙ Настройки → 💾 Экспорт.
2. В новом: там же → 📂 Импорт → выбрать сохранённый файл.
