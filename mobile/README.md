# «Мой прогресс» — приложение для Android (Expo)

Три экрана — **Сегодня**, **Еда**, **Прогресс** — и настройки за шестерёнкой.

- **Тренировки с часов Xiaomi** сами: Mi Fitness → Health Connect → приложение (тренировки, калории, дистанция, шаги, вес с весов).
- **Норма калорий меняется от тренировки**: база + доля сожжённого (по умолчанию 50%, меняется в настройках).
- **Подсказка на ужин**: сколько осталось ккал и белка и какие ужины лучше подойдут.
- Выбор блюд вместо плана, подсчёт по продуктам («гречка 150 г, 2 яйца»), свои блюда и продукты.
- Меню недели (3 меню по очереди), что приготовить вечером, список покупок.
- Вес, замеры, график, неделя по тренировкам, интервальный таймер.
- Напоминания (вода, взвешивание, замеры, таблетки) ставит сам телефон — сервер не нужен.
- Данные хранятся в телефоне; резервная копия — через «Поделиться», загрузка — из файла.
  Формат копии совместим с версией-сайтом (`index.html` в корне репозитория).

## Файлы

| Путь | Что это |
|---|---|
| `App.js` | Нижнее меню, синхронизация с часами, напоминания |
| `src/screens/` | Экраны: Сегодня, Еда, Прогресс, Настройки |
| `src/components/` | Шторка выбора блюда, интервальный таймер |
| `src/logic/core.js` | Вся «математика»: меню, съеденное, норма, подсказка на ужин, подсчёт по продуктам |
| `src/logic/health.js` | Чтение данных из Health Connect |
| `src/logic/reminders.js`, `notify.js` | Расчёт и постановка напоминаний |
| `src/data/menus.js`, `foods.js` | Меню, покупки, заготовки, база продуктов, блюда рациона |
| `src/ui.js`, `src/theme.js` | Кнопки, карточки, иконки, цвета, шрифт Onest |
| `scripts/test-logic.js` | Проверка логики: `npm test` |

## Собрать APK

Через сайт: expo.dev → проект «Мой прогресс» → Builds → **Build from GitHub** → профиль `preview`.

Или с компьютера в этой папке:

1. `npm install`
2. `npx eas-cli@latest build -p android --profile preview` (в PowerShell — `npm.cmd` / `npx.cmd`)

Перед новой сборкой увеличьте `android.versionCode` в `app.json` на 1 — тогда новая версия встанет поверх старой, данные сохранятся.

> Health Connect не работает в Expo Go — только в собранном APK.
